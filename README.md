# Sistema de Inventario para Tiendas de Abarrotes

Proyecto de la materia Introducción a la Economía, Facultad de Ingeniería, UNAM.

## Descripción
Desarrollo de un prototipo de software para facilitar el control de inventario en pequeñas tiendas de abarrotes.

## Objetivo
Ayudar a los negocios a registrar productos, controlar existencias y reducir errores en la administración de mercancía.

## Funciones propuestas
- Registro y edición de productos.
- Control de entradas y salidas.
- Alertas de existencias bajas.
- Consulta del inventario.
- Reportes básicos.

## Estado del proyecto
En planificación y desarrollo.

## Equipo
5 integrantes.

## Organización
- `src/`: código fuente.
- `docs/`: investigación económica y documentación.
- `tests/`: pruebas del sistema.
- `presentacion/`: material para la exposición.
